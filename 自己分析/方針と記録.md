# 自己分析：自然に続けたくなることを探す

## 今の状態

2026-10-02、将来に何をしたいのか、どんな仕事をしたいのか、なぜ起業したいのかがわからなくなっていることを整理した。これまで「人を楽しませたい」「みんなを幸せにしたい」という思いから、起業、イベント活動、社会人との交流などに積極的に取り組んできた。一方で、「やらなければ」と自分を動かし続けた結果、限界が来て「自分は本当は何がしたかったんだろう」とわからなくなっている。

これは現時点での本人の振り返りであり、過去の活動がすべて望まなかったものだと決めつけるものではない。将来の職業や起業を急いで決めず、実際の経験から自分の関心や満足感を観察する。

## 当面の方針

- 「やらなければ」ではなく、「気づいたらやってしまうこと」「またやりたいこと」を探す。
- 音楽・ドラム、ものづくり、イベント、チーム活動などを、小さく実際に試す。
- 休息が必要なときは休み、疲れているのに無理をして続けることを観察の条件にしない。
- 起業や職業は、観察材料が集まってから考える。今すぐ結論を出す必要はない。

## 経験ごとの記録

活動の直後、できれば短く記録する。点数は正解を出すためではなく、経験ごとの違いを見るための目安。

| 日付・活動 | 最中の楽しさ (0–10) | 終了後の満足感 (0–10) | またやりたい (0–10) | 人が楽しむことの喜び (0–10) | 疲れていてもやりたい (0–10) | 誰にも評価されなくてもやりたい？ | メモ |
|---|---:|---:|---:|---:|---:|---|---|
|  |  |  |  |  |  |  |  |

「疲れていてもやりたい」は無理を推奨する項目ではない。体調を崩してまで行う必要はなく、そう感じるかどうかを振り返るだけにする。

## これからすること

1. まずは音楽・ドラム、ものづくり、イベント、チーム活動から、負担の小さいものを一つ選んで試す。
2. 活動の直後に上の項目を記録する。できなかった日は空欄でよい。
3. 何回か経験したら、活動の種類ごとに「最中の楽しさ」「終わった後の満足感」「またやりたい気持ち」を見比べる。
4. 「人を楽しませたい」という気持ちと、自分自身がその活動を楽しんでいるかを分けて振り返る。
5. 点数だけで決めず、どんな場面で自然に集中したか、何が負担だったかも短く残す。
6. 振り返りをもとに、続ける・やり方を変える・いったん休むを選ぶ。職業や起業の結論は急がない。

## 現時点で保留する問い

- 自分が楽しみたいことと、他人を楽しませたいことは、どの活動で両立するか。
- 評価、期待、義務感がなくても続けたい活動は何か。
- 活動そのもの、準備、仲間との協働、完成や発表のうち、どの部分に満足を感じるか。
- 起業したい気持ちは今もあるのか。あるなら、何を実現したいからなのか。

これらはすぐに答えを決める質問ではなく、経験を重ねながら更新する。
