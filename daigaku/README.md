# 大学の授業・テスト

大学の授業内容・課題・テスト対策をまとめる場所。

## 使い方

- 授業ごとに `daigaku/<科目名>/` を作って、講義メモ・課題・テスト範囲などをまとめる。
- 単発のメモ（次回の課題締切、小テストの範囲など）はこのディレクトリ直下や `notes/memo.md` に書けば十分。
- 課題・テストの期日は `daigaku/deadlines.md` の表に追記する。クラウドの定期ルーチン（毎朝8:00 JST）が読んで、スマホ・PCに自動通知する（通知タイミングは種別と残り日数から自動判断、最低3回）。変更は push しないとクラウドに反映されない。
- テスト前にまとめた要点や過去問の振り返りなどはこの下に残しておく。
